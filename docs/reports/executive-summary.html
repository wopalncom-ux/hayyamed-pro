Overview

Hayya Med Pro is a production-deployed, AI-powered healthcare compliance SaaS platform. It helps GCC healthcare professionals track CME/CPD credits, manage license renewals, and stay compliant with all 7 GCC licensing authorities — in one platform. The company was founded in Qatar, is registered at hayyamed.pro on GCP Cloud Run (me-central1, Doha region), and has completed 56+ development sessions totaling 73 git commits, 176 pages, 62 API routes, 33 database migrations, and 8 live AI modules.

The Problem

700,000+ licensed healthcare professionals in GCC — each with a personal compliance clock. Every professional must complete 30–80 credits of CME/CPD per renewal cycle, across 7 different authorities with incompatible portals and rules. Today, most track compliance in spreadsheets (or don't track at all). Employers have zero real-time visibility into whether their staff will pass the next JCI audit. License lapses happen silently, discovered only at renewal — months too late.

The Compliance Gap Is Expensive

A lapsed license = suspended income for the professional. A non-compliant workforce = failed JCI/CBAHI accreditation for the hospital. Today there is no single GCC-focused platform that solves this — for individuals or employers.

Our Solution — The Platform Moat

GCC Rules Engine

All 7 authorities configured in DB — not hardcoded. Admin panel updates rules; zero code deploy needed. Takes 12–18 months to replicate accurately.

Multi-Authority Wallet

One login → compliance across QCHP + SCFHS + DHA simultaneously. No competitor offers multi-jurisdiction tracking in one platform.

AI Certificate Reader

Photo your CME certificate → Claude Vision reads it → form auto-populated in 8 seconds. Arabic and English. Pro/Employer tier only — AI cost is zero for free users.

Built-in-Qatar Trust

Data stays in GCC (me-central1 Doha). PDPL-aligned by design. Critical for QCHP, HMC, and government procurement conversations.
