OWASP Top 10 — 2021 Assessment
A01
Broken Access Control PASS
RLS enabled on ALL 78 database tables. RBAC implemented via organization_members with roles: healthcare_professional, employer_admin, training_provider_admin, master_admin, super_admin. Every API route calls getUser() before data access. Admin routes additionally verify role. MFA (AAL2) enforced on /admin routes.
✅ No privilege escalation vectors identified. Ownership checks (WHERE auth_id = user.id) consistent across endpoints.
A02
Cryptographic Failures PASS
HTTPS enforced via HSTS (max-age=63072000, includeSubDomains, preload). Supabase handles password hashing (bcrypt). MFA recovery codes stored as SHA256 hashes — plaintext never persisted. Certificate files served via signed URLs only (private bucket). No sensitive data in localStorage (session in HTTPOnly cookies).
✅ upgrade-insecure-requests in CSP for production. No cleartext credential storage identified.
A03
Injection PASS
Supabase SDK uses parameterized queries exclusively — no raw SQL string concatenation found. Zod schema validation on all POST bodies before database operations. No eval() found in codebase. Path traversal: certificate storage uses uuid-based paths (no user-controlled filenames in paths).
⚠️ Admin email campaign page renders user HTML with dangerouslySetInnerHTML without DOMPurify sanitization. Admin-only, low risk but should be fixed.
A04
Insecure Design PASS
Free tier limits enforced server-side (never client-side only). AI features tier-gated at API level. Certificate storage is private bucket with signed URLs. PDF reports require Pro subscription check server-side. Account deletion requires explicit { confirm: true } body. Rate limiting prevents enumeration attacks.
✅ Defense in depth: middleware + API + RLS — three layers of access control.
A05
Security Misconfiguration PASS
All 7 security headers configured in next.config.ts. CSP allowlist (not blocklist). X-Frame-Options: DENY prevents clickjacking. Permissions-Policy blocks camera/microphone/geolocation. Service role key: autoRefreshToken=false, persistSession=false (one-time use, not leaked). COMING_SOON gate enabled by default.
✅ Sentry DSN public is acceptable (source maps separate). Server actions restricted to production domains.
A06
Vulnerable & Outdated Components REVIEW
All 41 dependencies at current/recent versions (Next.js 16.2.6, React 19.2.4, Supabase 2.107.0, Anthropic 0.102.0). No obvious outdated packages. However: no automated dependency scanning in CI/CD pipeline. No Snyk, npm audit, or Dependabot configuration found.
⚠️ Recommend: Add npm audit check to Cloud Build pipeline. Enable Dependabot on GitHub for automatic security PRs.
A07
Authentication Failures PASS
Supabase handles all auth (bcrypt hashing, session management). MFA TOTP enforcement for admin routes (AAL2). Rate limiting on auth: 10 req/60s per IP. Account deletion rate limited (3/hr). No brute force vulnerability via API (Supabase auth built-in protections + Upstash rate limiter). Password reset via email (no enumeration — same response for existing/non-existing).
✅ MFA recovery codes SHA256-hashed. One-time use enforced. Session stored in HTTPOnly cookies.
A08
Software & Data Integrity Failures PASS
No deserialize operations found. Paddle webhook validated via signature (getPaddle().webhooks.unmarshal()). Server actions restricted to allowedOrigins: [hayyamed.pro, Cloud Run URL]. CSRF protection automatic via Next.js server actions. Supply chain: package-lock.json present for reproducible builds.
✅ No untrusted deserialization. Payment webhook integrity verified cryptographically.
A09
Security Logging & Monitoring Failures PASS
Sentry integration for error tracking (source maps, tunnel route). Comprehensive audit_logs table (append-only, 7-year retention). Every admin action logged: actor_id, actor_role, action, target_type, target_id, metadata. AI calls logged: model, tokens, cost, latency, professional_id. Payment events logged. Account deletion logged before cascade.
⚠️ No alerting on audit_log anomalies (e.g., mass data export, unusual admin actions). Recommend: Add PostHog or GCP alerting on suspicious audit events.
A10
Server-Side Request Forgery (SSRF) PARTIAL
Performance dashboard fetches external PageSpeed Insights API. URL validation restricts targets to hayyamed.pro or localhost. However: Email campaign API calls Postmark with admin-provided email addresses (minimal SSRF risk). AI endpoints use fixed Anthropic/Vertex URLs (not user-controlled).
⚠️ Verify: Any endpoint that fetches a user-supplied URL must validate against allowlist. Found 1 SSRF protection (PageSpeed). Audit remaining external HTTP calls.

🟡 MEDIUM-01 — Unsanitized HTML in Admin Email Composer
File: app/(admin)/admin/email-campaigns/page.tsx
Pattern: dangerouslySetInnerHTML={{ __html: htmlBody }}
Risk: Admin user or compromised admin account could inject malicious scripts into email preview. Admin-only, so blast radius is limited, but defense in depth requires sanitization.
Remediation: Install DOMPurify (npm install dompurify @types/dompurify). Wrap with DOMPurify.sanitize(htmlBody) before rendering.
Effort: 1 hour. Priority: Do before inviting other admins.
🟡 MEDIUM-02 — Missing SSRF Audit on All External HTTP Calls
SSRF protection verified only on PageSpeed Insights endpoint. Full inventory of external HTTP calls (Postmark, Paddle, Anthropic, web push endpoints) should be audited to confirm all use fixed/trusted URLs, not user-supplied values.
Remediation: Document all external outbound HTTP calls. Confirm none accept user-supplied URLs without strict allowlist validation.
Effort: 4 hours (audit) + minimal fixes.
🟡 MEDIUM-03 — No Automated Dependency Vulnerability Scanning
No Snyk, Dependabot, or npm audit in CI/CD pipeline (cloudbuild.yaml). A vulnerable dependency could be introduced undetected.
Remediation: Add npm audit --audit-level=high as a Cloud Build step. Enable GitHub Dependabot security alerts.
Effort: 2 hours.
🔵 INFO-01 — No File Type / Size Validation on Certificate Upload
Certificate upload endpoint should explicitly validate file type (PDF/image only) and enforce max size (e.g., 10MB). Current implementation relies on Supabase storage defaults. Effort: 2 hours.
🔵 INFO-02 — Silent Cookie Error in Middleware
lib/supabase/middleware.ts: cookie.setAll() wrapped in silent try/catch. Error is suppressed with no logging. Effort: 30 minutes.
🔵 INFO-03 — No Webhook Retry Logic for Failed Paddle Events
If Paddle webhook handler fails (DB error, timeout), the event is lost. Paddle retries on HTTP error, but if the handler returns 200 after partial processing, data is inconsistent. Implement idempotent webhook processing with a processed_webhooks table. Effort: 1 day.
🔵 INFO-04 — VAPID Keys Should Be Rotated Quarterly
Web push VAPID keys are long-lived. No rotation schedule documented. Recommend quarterly rotation procedure. Effort: Document procedure only.
