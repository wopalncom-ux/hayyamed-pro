Issues Found — Prioritized
🟠 HIGH — User-Facing PDF Compliance Report Missing
The primary Free→Pro conversion driver (per CLAUDE.md) is not yet built. Admin can generate reports for users, but users cannot self-serve their compliance PDF. This is blocking revenue directly. Effort: 2 days. Impact: Primary conversion driver.
🟠 HIGH — Unit Test Coverage: ~0%
Only Playwright E2E tests found. No Jest/Vitest configuration in package.json. Compliance calculation logic, subscription entitlement checks, and country rules engine have zero automated test coverage. Risk: Regression bugs in production with no safety net. Effort: 5 days to reach 60% on critical paths.
🟡 MEDIUM — Next.js Image Component Underutilized (2 of 200+ instances)
Only 2 usages of next/image found. All other images are raw <img> tags or background CSS. This causes CLS (Cumulative Layout Shift) and prevents AVIF/WebP optimization. File: Landing page, blog images, profile photos. Effort: 1 day. Impact: Lighthouse performance +15-20 points.
🟡 MEDIUM — No Suspense Streaming on Dashboard
Dashboard page (365 lines) loads as a single server render waterfall. Adding Suspense boundaries would allow streaming, reducing time-to-first-byte and improving perceived load speed. Effort: 1-2 days. Impact: LCP improvement 200-500ms.
🟡 MEDIUM — MFA Recovery Uses Manual HTTP Call to Supabase API
File: app/api/auth/mfa/recovery/route.ts lines 102-112. Manual fetch() to Supabase REST endpoint instead of SDK method. Risk: Error handling inconsistency with SDK behavior, future API version breaks. Effort: 2 hours.
🟡 MEDIUM — No Revalidate Cache Strategy on Server Actions
Server actions that mutate data (CME add, license update, profile change) do not call revalidatePath() or revalidateTag(). Next.js caches responses by default — this could serve stale data after mutations. Effort: 1 day. Impact: Data consistency.
🔵 LOW — Silent Cookie Failure in Middleware
lib/supabase/middleware.ts cookie.setAll() wrapped in try/catch with no logging. Middleware failures are invisible in logs. Add console.warn() or Sentry capture. Effort: 30 minutes.
🔵 LOW — No Loading States on Admin Routes
Admin pages load synchronously without loading.tsx fallbacks. Heavy admin pages (logs center, exports) show blank content during data fetch. Effort: 4 hours.
