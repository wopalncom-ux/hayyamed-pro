Step 7 of 7 — Go Live
7

Set COMING_SOON = false → trigger deploy → verify live

The single switch that opens the platform to the public

~10 min
🚀

This is the go-live action. No code change needed. One substitution variable change triggers a full build and deploy. The public marketing site goes live immediately on successful deploy.

Option A — Via GCP Console (recommended)

  • Open Cloud Build Triggers.

  • Click the hayyamed-pro trigger → Edit.

  • Under Substitution variables, find _COMING_SOON and change the value from true → false.

  • Also set all Upstash and VAPID secrets from Steps 3–4 if you haven't already (they take effect on this deploy).

  • Click Save, then click Run Trigger to start the build immediately.

Option B — Via gcloud CLI

# Trigger the build with COMING_SOON=false
gcloud builds triggers run hayyamed-pro \
  --substitutions=_COMING_SOON=false \
  --project=project-38d955b0-84e7-44b6-8b5 \
  --region=global
